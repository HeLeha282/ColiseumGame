## 2026-11-12 — Серый прототип, этапы 1–2: Колизей и игрок (Davidik31 + Claude)

**Сделано:**
- **Генератор прототипа** `Assets/_Project/Editor/PrototypeBuilder*.cs`, меню **ColiseumGame → Build Prototype**.
  Он создаёт материалы, конфиги (ScriptableObject), все префабы и заново собирает сцену `Prototype.unity`
  из префабов, а потом запекает NavMesh. Есть ещё **ColiseumGame → Rebake NavMesh**.
  - Префабы и сцена при каждом запуске генератора **пересоздаются**, ручные правки в них пропадут.
    Конфиги баланса в `ScriptableObjects/` создаются **только если их нет**, так что их можно спокойно править.
    Если начнёте вручную править сцену или префабы, генератор больше не запускайте (или перенесите правки в его код).
- **Код** — сборка `ColiseumGame.asmdef` (`Assets/_Project/Scripts`), редакторный код — `ColiseumGame.Editor.asmdef`.
- **Колизей** (префаб `Prefabs/Environment/Coliseum`): арена r=30 м (y=0), 1-й ярус r 30–38 (y=3),
  2-й ярус r 38–45 (y=6), внешняя стена до 11 м, 4 арки-спавна на 2-м ярусе (углы 45/135/225/315°),
  8 пандусов. Ярусы — кольца из 72 кубов, геометрия на примитивах (ProBuilder не понадобился).
- **Портал** в центре: светящийся цилиндр с HP (800), по мере урона краснеет. Обходится NavMesh через NavMeshObstacle (carve).
- **Маршруты** (префаб `Routes`, 4 объекта `Route_N`): точки маршрута — это дочерние объекты по порядку,
  их можно двигать/добавлять, линии видны в Scene view (гизмо). Спираль: по 2-му ярусу ~80° по часовой → пандус →
  ~80° по 1-му ярусу → пандус на арену → к порталу. Длина маршрута ~146 м (~40 с ходьбы пешего).
- **NavMesh**: `NavMeshSurface` на корне Колизея (собирает только его коллайдеры), данные — `Scenes/Prototype_NavMesh.asset`.
  Проверено скриптом: все 4 маршрута проходимы целиком.
- **Игрок** (префаб `Prefabs/Player/Player` + `CameraRig`): капсула на CharacterController, WASD, Shift — бег, пробел — прыжок, HP 200,
  после смерти возрождение через 5 с у портала.
  - Камера: **V** переключает режимы. 3-е лицо — `CinemachineFreeLook` (свободная орбита, WorldSpace, как в Genshin,
    персонаж разворачивается по ходу движения), с CinemachineCollider против стен. 1-е лицо — vcam в голове персонажа, мышь крутит тело и голову.
  - Мышь из нового Input System передаётся в FreeLook через `FreeLookInputProvider` (официальный интерфейс Cinemachine).
  - Оружие: **1 — меч** (ЛКМ, дуга 130°, 2,8 м, по высоте достаёт ±2 м — летунов почти не достать),
    **2 — лук** (держать ЛКМ — натяжение 1 с, урон 10→45 и скорость стрелы растут, отпустить — выстрел в точку под прицелом).
- **Ввод** — свой ассет `Settings/ColiseumControls.inputactions`, всё читается через `InputReader`.
- TextMesh Pro Essentials импортированы и перенесены в `Assets/ThirdParty/TextMesh Pro` (так требуют правила про сторонние ассеты).
- Закоммичены и изменения настроек URP, которые Unity сама сделала при первом открытии проекта
  (`UniversalRenderPipelineGlobalSettings.asset`, Graphics/Quality settings).

**Проверено в Play Mode через MCP:** консоль без ошибок; бег/прыжок, переключение камеры, удар мечом (урон + метка),
стрела из лука попадает и убивает; враги идут по маршруту через оба пандуса до портала.

**Решения:**
- Сцену и префабы собирает код, а не ручная работа через MCP: так результат воспроизводим и его легко поменять (размеры, маршрут).
- Камера 3-го лица смотрит чуть выше головы (точка на высоте 2,3 м): персонаж оказывается под прицелом и не закрывает цель.
- Все числа (скорости, урон, HP) — в `PlayerConfig`/`EnemyConfig`/`TowerConfig`/`WaveConfig`/`GameBalance`.

**Для тестов через MCP:** чтобы виртуальные нажатия доходили без фокуса окна Game, в Play Mode нужно выставить
`Application.runInBackground = true` и `InputSystem.settings.editorInputBehaviorInPlayMode = AllDeviceInputAlwaysGoesToGameView`
(это меняется только в памяти, в проект не сохраняется).

**Сделано:**

- Создан Unity-проект на **Unity 2022.3.10f1** с **URP 14.0.8** (собран из командной строки: базовый 3D + URP,
  потому что шаблона 3D URP в установленном Unity не было).
- URP-ассеты: `Assets/_Project/Settings/URP_PipelineAsset.asset` и `URP_Renderer.asset`,
  назначены в Graphics и во всех уровнях Quality.
- Настройки: Color Space = Linear, Asset Serialization = Force Text, Visible Meta Files,
  Active Input Handling = Both (новый Input System + старый, чтобы не ломались сторонние паки).
- Пакеты: Input System 1.7.0, Cinemachine 2.9.5, ProBuilder 5.1.1, AI Navigation 1.1.4, TextMeshPro.
  Удалены лишние пакеты, которые Unity добавляет по умолчанию: Ads, Purchasing, Analytics, Collab, VSCode.
- Стартовая сцена: `Assets/_Project/Scenes/Prototype.unity` (пока только камера, свет и плоскость-пол).
- `.gitignore` / `.gitattributes` дополнены (LFS для gif/bmp/psb/aiff/flac/Maya/Max/Substance/lightingdata;
  текстовые типы Unity: inputactions, shadergraph, asmdef и др.).
- Подключён MCP-сервер для связи Claude Code с редактором Unity (см. ниже). Конфиг — `.mcp.json` в корне.

**Решения и почему:**
- **Unity 2022.3.10f1**, а не Unity 6: эта версия уже стояла, на ней всё работает. У обоих разработчиков
  должна быть **ровно эта версия**, иначе сцены/настройки будут конфликтовать.
- **ProBuilder** — чтобы строить серый Колизей (ярусы, лестницы, арки) прямо в Unity без Blender.
- **AI Navigation (NavMesh)** — для движения врагов по маршруту.
- **Cinemachine 2.9.5** (а не 3.x) — эта версия идёт вместе с Unity 2022.3, по ней больше туториалов.
- **MCP: CoplayDev/unity-mcp v10.3.0** (пакет `com.coplaydev.unity-mcp`). Сравнивали три варианта:
  - CoplayDev/unity-mcp — поддерживает Unity 2021.3–6.x, работает локально, MIT, ~50 инструментов
    (сцены, объекты, скрипты, консоль, тесты, сборка), самый популярный. **Выбран.**
  - CoderGamester/mcp-unity — текущая версия требует Unity 6+, отпал.
  - IvanMurzak/Unity-MCP — по умолчанию работает через облако ai-game.dev (данные проекта уходят наружу),
    очень частые релизы, минимальная версия Unity не указана. Отпал.
  - Пакет зафиксирован на теге `v10.3.0`, сервер — `mcpforunityserver==10.3.0` через `uvx`.
    Версии обновляем только вместе и записываем сюда.

Git + Git LFS, Unity Hub + Unity 2022.3.10f1, Python 3.10+, `uv` (`winget install astral-sh.uv`), Claude Code.
